# UF850 + OnRobot VGC10 — four cups in a 2x2 layout

## User-confirmed hardware

- **Robot:** UFACTORY UF850 (not the gantry used to generate existing demonstrations).
- **End effector:** **OnRobot VGC10**, **four suction cups** arranged as a **2 x 2 matrix**.
- **Vacuum:** VGC10 contains **two air channels, A and B**. Four cups do **not** imply four independent vacuum controllers. Whether the channels are separated or joined depends on the actual adapter routing.
- **Camera:** Fixed overhead RGB camera, optical axis down, image aligned with the conveyor travel direction, viewing conveyor and pickup station.

Manufacturer VGC10 reference: https://onrobot.com/storage/datasheets/datasheet_vgc10.pdf

## Current simulation fidelity

The included model is a **visual/collision and URDF kinematic proxy only**:

| Component | Implemented | Not implemented |
| --- | --- | --- |
| VGC10 housing | Nominal 101 x 100 x 100 mm geometry | Manufacturer CAD |
| Mass | 0.814 kg nominal mass split among four cup/body proxies | Validated detailed inertia |
| Cups | Four cylindrical proxies in a 2x2 pattern | Elastomer deformation and suction sealing |
| Channels | Labels A and B, two cups per channel by default | Pressure, air flow, separate valve/command dynamics |
| UF850 | URDF augmentor to combine with generated robot | Spawned / controlled UF850 in Gazebo Harmonic |
| Gantry baseline | Visual-only four-cup proxy | Real UF850 kinematics or physical vacuum pickup |

**Assumed dimensions (must be checked on your real gripper):** 30 mm cup diameter, 50 mm pitch X, 50 mm pitch Y. The default A/B routing uses the positive-Y row as A and negative-Y row as B; if your plate is rotated, use `--channel-axis x` or update the map to match its actual plumbing. The tool flange mounting transform and TCP are also unverified.

## Apply geometry to existing gantry baseline

From the project root, after applying the v2.1 patch:

```bash
python3 scripts/visualize_vgc10_on_gantry.py \
  --world simulation/worlds/conveyor_station.sdf \
  --cup-mm 30 --pitch-x-mm 50 --pitch-y-mm 50 --channel-axis y

docker compose restart sim
```

This changes **visuals only**; the existing attached-joint demonstration and saved Gazebo Z joint limit remain untouched. It is safe to rerun: previous VGC10 visuals are replaced, not duplicated. This is useful for camera occlusion but is **not a working VGC10 vacuum gripper**.

## Generate VGC10 attachment on a real UF850 URDF

Generate a complete UF850 URDF from UFACTORY's `xarm_ros2` Jazzy branch: https://github.com/xArm-Developer/xarm_ros2. Do not pass a xacro macro file directly to the script.

```bash
python3 scripts/uf850_tool_urdf.py \
  /path/to/generated/uf850.urdf \
  simulation/generated/uf850_vgc10.urdf \
  --flange link6 \
  --cup-mm 30 \
  --pitch-x-mm 50 \
  --pitch-y-mm 50 \
  --channel-axis y
```

Use `--flange` to select the **actual flange link name** in your generated URDF. Verify `--mount-xyz`, `--mount-rpy` and the `vgc10_tcp` offset against your **real** flange adapter and cup protrusion. Importing and controlling the UF850 in Gazebo Harmonic remains additional integration work.
